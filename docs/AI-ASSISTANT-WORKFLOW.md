# AI 辅助与人工确认

本说明对应整项目收尾实现，优先于此前文档中“AI 权限、工具、策划待实现”的阶段性记录。仅描述已落地的轻量功能，不包含 MCP 协议、多智能体或 DAG 引擎。

## 使用入口

- 学生登录后进入 `/assistant`：社团与活动查询、资料问答、历史会话和兴趣推荐。
- `/system/knowledge`：查看当前可见资料。平台管理员上传 PUBLIC 资料；所属负责人上传 CLUB 资料；普通学生只能读取。
- 负责人进入 `/manage/activities`：手工建活动，或生成策划参考、修改、人工确认保存草稿，再单独确认发布。
- 正式开发模式的收藏保存到账号；纯原型依旧是浏览器本地记录，旧本地收藏不会自动导入账号。

## 数据和信任边界

浏览器请求先经过校园服务的 Session 与 CSRF 校验。校园服务从数据库生成账号、角色、成员社团及负责社团范围，再通过带共享密钥的内部 HTTP 请求传给 AI 服务；不信任浏览器自己填写的 userId、角色或身份请求头。共享密钥仅存后端环境变量 `AI_INTERNAL_TOKEN`。

知识检索先筛选 PUBLIC 和当前成员社团的 CLUB 文档，再计算相关性。非成员访问社团文档统一返回 404。PLATFORM_ADMIN 不自动拥有社团内部资料权限。文档哈希包含内容、模型版本和可见范围，不把相同内容的私有资料去重成公开资料。

会话由服务器生成 UUID，首轮成功后绑定当前账号。续聊、历史与列表均校验归属，不接收客户端自建新会话编号。旧的无账号归属会话保留原记录但不分配给任何新账号。历史读取重新检查引用权限；引用权限已撤销的回答会隐藏正文、出处及工具观察。Redis 仅保存有账号/当前社团范围的短期上下文，必须与当前已授权数据库内容一致才采用；失败时读数据库，不覆盖持久历史。

## 两种对话

资料问答（RAG）：问题 → 可见资料检索 → 模型整理或 LOCAL 原文摘录 → 返回回答与片段出处 → 保存本人会话。模型事实回答必须包含本次有效资料编号；纯粹的“资料未说明。”不要求凭空引用。缺失或编号越界返回 502，不自动伪造来源。编号校验并不证明模型每个结论都正确，仍需查看原文。

社团与活动助手（轻量 ReAct）：模型选择一个白名单动作 → 服务执行真实只读查询 → 将结果交回模型 → 模型结束或再次查询。最多 3 次工具调用、4 次模型请求；超限、非法动作、格式错误或过大上下文会明确失败，不假装完成。前端显示工具名称、参数和实际结果，不显示模型思维过程。

白名单只有 `search_clubs`、`get_club`、`search_activities`、`get_activity`、`my_registrations`、`search_knowledge`。本人报名工具的身份由服务器固定，不由模型指定。没有发布、报名、审批、支付、任意 URL 或执行代码工具。社团/活动列表分别最多 10 条，本人报名最多 20 条；结果不是全量报表。LOCAL 模式只做固定工具查询，返回明确说明，不能称为模型 ReAct。

这是内部 HTTP 工具，不是已经接入外部 MCP。也没有“每个环节都运行一次 ReAct”的 DAG。以后需要天气等外部数据时，可单独增加协议适配、权限与测试，不改变正式业务数据归属。

## 活动策划与 HITL

负责人填写目标 → 生成标题和介绍/简要流程 → 人工修改文案并填写真实时间、地点、人数 → 弹窗核对 → `PUT /api/manage/clubs/{clubId}/drafts/{requestId}` 保存 DRAFT → 列表再次确认发布。

生成阶段不保存活动、不预订场地、不设置预算、不发起审批。模型输出只作参考，负责人对实际安排负责。时间/名额等约束仍由校园服务执行。相同 UUID 与相同内容重试返回同一条草稿；改变内容复用编号返回 409。前端首次确认后冻结本次编号和内容，响应丢失可按同样内容重试，不自动另建草稿。未发送的确认可返回编辑；已发送的确认须先核对或重试，保存成功后再从列表编辑。

当前待确认内容只保留在当前页面运行状态。刷新/离开前若响应丢失，应先核对活动列表，不承诺浏览器崩溃后的待确认表单恢复。发布仍是独立按钮，不因为生成成功或保存成功而自动执行。

## 故障与限制

校园业务不调用 AI：模型、AI 服务或 Redis 不可用时，资料、社团设置、招新审核、活动、签到、经费、收藏、通知继续使用校园数据库。AI 返回明确错误，不默默用标签推荐、模板或本地摘录冒充真实模型输出。LOCAL 是明确选择的配置，不是模型失败后的自动回退。

模型单次读取超时 60 秒，校园到 AI 请求上限 300 秒；本机模型可能较慢。工具结果与历史有长度上限，不能当成全校大数据检索或生产并发能力。知识资料仍仅支持 UTF-8 TXT/MD、单文件 128KB。未实现流式输出、限流、多实例会话、学校 SSO、密码找回和正式用户权限管理。

自动验证：后端 `mvn -DskipTests=false test`；前端 `npm run test:ai-workflows`。真实本机模型与整业务验收：`node scripts/check-completion.mjs`；重启两个服务后使用 `restored`，只停止 AI 时使用 `offline`。脚本创建独立虚构学生、内部文档和未来活动，保留记录，不改旧验收数据。小量模型演示不等于推荐质量或安全审计结论。
