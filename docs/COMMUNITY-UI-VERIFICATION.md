日期：2026-10-05 完成界面调整，2026-10-06 完成继续验收。范围为当前前端全部可访问页面，不限于底部菜单。未新增后端功能或自动 AI 操作。

## 全页面清单

| 区域 | 路由 | 界面处理 |
| --- | --- | --- |
| 学生主入口 | /、/clubs、/recruitment、/activities、/assistant、/me | 统一页头、白底列表、绿色操作、手机六入口与桌面侧栏 |
| 账号 | /login | 简洁账号密码表单、加载/错误反馈、演示账号折叠说明；保留密码管理器支持 |

App.vue 只使用 CommunityShell。SystemShell 改为内容内的联调导航，不再生成另一套侧栏。负责人导航在共享外壳中显示。次级页面共用 community-secondary.css，登录、详情、说明、原型活动列表和工作台标题进行了内容/布局调整，不只是改变颜色。

## 设计依据与保留边界

以用户认可的社群列表为准：文字 #242827、次要文字 #69716e、操作绿色 #168169、底色 #f5f6f6、白色 #fff、分隔线 #eceeed；系统中文字体。小标题与内容优先，不加入营销横幅、英文装饰标签、渐变或多余动效。

frontend-design 用于删去宣传式标题与装饰，ui-ux-pro-max 用于共用控件、触摸尺寸、可读性与响应式检查。搜索工具给出的营销型通用配色不适合已确认界面，采用已有设计约束，不引入新字体、依赖或验证库。按照用户要求保留六个底部导航入口。

- 原有申请、审核、成员、草稿/发布、报名/取消、通知、原型兴趣与本地收藏逻辑保留。
- 正式模式不把数据库错误替换成模拟数据；原型模式不请求业务接口。
- 注册、资料编辑、社团维护、签到、经费及账号收藏等部分后端接口尚未接入页面；本次未新增这些功能。经费页明确显示“页面未接入”，不把接口已存在说成后端未实现。
- 资料问答仍只读；LOCAL 是关键词检索与原文摘录，不称为模型生成或语义检索。未新增推荐、ReAct、MCP 或 DAG。
- 未修改校园后端、AI 服务或原始 PaiSmart 项目代码。继续验收时发现本地服务均已停止，使用原 start-dev.ps1 重新启动当前项目的三个服务，没有改配置或启动原始 PaiSmart。旧原型归档与 ZIP 保持不变。
- 未路由使用的旧页面文件仍保留，没有做无关文件清理；这些不是当前产品可访问页面。

- TypeScript + Vite 正常构建通过；纯前端静态构建通过，没有发布公网。

- 实际截图查看：手机登录、社团详情、申请弹窗、负责人审核、活动表单、资料问答；桌面资料知识库。保存关键截图与布局 JSON 至 .run/all-pages-ui-2026-10-05/。
