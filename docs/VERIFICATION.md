## 测试位置与重跑

自动化测试：`CampusApiTest`、`KnowledgeChatTest`、`RetrievalTest`、`ModelClientTest`、`ModelRagIntegrationTest`，共 13 个用例。根目录执行 `mvn -DskipTests=false test`。

前端检查：在 `frontend` 执行 `npm run build`。

默认本地模式联通：启动三个进程后执行 `node scripts/smoke.mjs`。此检查会上传一份明确标注的模拟资料、保存一轮测试问答，结果在 `.run/smoke-result.json`。

故障隔离检查：停止本项目 AI 服务后执行 `node scripts/check-resilience.mjs down`；恢复三个进程后执行 `node scripts/check-resilience.mjs restored`。后者检查之前保存的记录，不另造一份问答替代旧记录。

## 尚未验证或实现

真实供应商的模型及 Embedding 调用尚未验证，需填写自己的模型配置；模拟接口测试只验证代码和协议链路，不证明模型效果。

MySQL profile 与 Redis 缓存已提供配置和代码，但尚未做真实实例联调。默认 H2 文件库已验证。没有连接原 PaiSmart 的数据库或 Redis 数据。

登录、社团归属权限、招新审核、活动报名、兴趣推荐、活动策划、人工确认及 ReAct/MCP/DAG 都未实现。本次没有推荐质量、并发报名或真实校园用户实验。
