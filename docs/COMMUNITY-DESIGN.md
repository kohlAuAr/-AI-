# 社群列表重建设计

2026-10-04。用户明确要求停止旧版换色，参考知识星球的星球/社群列表，不是帖子动态页。

## 范围与参考

重写 `/clubs` 的页面和导航外壳，源码独立在 `frontend/src/community/`。不复用旧 `p-*` 布局和卡片样式，不继续蓝色营销页；其他页面暂时保留以避免擅自扩展全站重做。社团详情和入社接口仍沿用现有业务能力。

参考知识星球官方产品说明：https://www.zsxq.com/、https://doc.zsxq.com/newcomer-guide.html。官方说明确立社群、内容和搜索定位，但不是用户目标小程序的逐像素截图。本次采用手机社群列表的视觉方向，未复制官方品牌、付费功能、内容或界面资产。官方网页列表的自动浏览连接未成功，不宣称已核对最新微信小程序的每一个细节。

## 设计决策

以内容和入口为主：普通页头、短搜索框、文字类别、左封面右信息的列表行；不用大幅口号、装饰插画、渐变、悬浮卡片网格、营销统计、英文字母标签或轮播。手机单列列表和底部导航；电脑为侧边导航、列表、我的社团三个区域。

```
手机                         电脑
社遇 / 消息 / 账号             社遇 / 账号
社团         我的申请          导航 | 社团列表 | 我的社团
搜索社团或兴趣                      | 搜索分类 | 入社申请
全部 科技 文艺 运动 公益             | 封面 信息|
封面 | 名称 简介                    | 封面 信息|
     | 类别 成员 时间地点
发现 社团 招新 活动 助手 我的
```

颜色：正文 `#242827`、次要文字 `#69716e`、操作强调 `#168169`、底色 `#f5f6f6`、列表白色 `#ffffff`、分隔 `#eceeed`。系统中文无衬线字体；标题 21–22px，社团名称 16–17px，简介 14px，元信息 12px。采用独立 SVG 图标和封面，不引入图片外链和依赖。

frontend-design 用于重新组织产品结构，而非套营销首页模板；UI UX Pro Max 用于点击区、状态语义、紧凑文字和焦点检查。其自动营销布局/紫色主题不符合用户参考，未采纳，不称其为匹配成功的方案。

## 业务与原型保护

- 继续从 `clubCatalog` 读取，正常模式为后端，纯原型模式为虚构数据；没有给界面伪造活跃人数、帖子数、更新时间或负责人。
- 搜索原有名称、兴趣标签与简介；按原有分类过滤。
- 点击列表打开原有详情，入社审核链没有改变；右侧已加入列表只读取真实成员关系。
- 收藏沿用浏览器本地行为，界面明确说明。没有新建帖子、社群聊天或付费等业务。
- 加载失败不展示旧缓存为可用社团，单独给出重试入口；保持本地数据说明。
- 六个底部入口和助手入口保留。正常与公共纯原型入口使用同一新列表，公共模式禁用业务 API；没有开启公网。
- 之前 rejected 页面源码保存于 `.run/community-rebuild-before-2026-10-04/`；旧 Catalog 恢复修改前逻辑，仅供未重做的招新与活动页使用。2026-10-01 原型归档不修改。

## 验证

- `npm run build`：通过，包含 Vue/TypeScript 检查及 Vite 构建。
- `npm run test:prototype`：通过，76 条断言、22 个原型路由；涵盖六个社团列表、搜索入口、分类状态与底部助手入口。
- `npm run test:business`：通过，Mock HTTP + SSR 验证原有登录、CSRF、申请、负责人审核、成员关系及失败提示；不是本次重新执行真实申请审核。
- 公共纯原型 Vite 构建：通过，没有启动公网服务。
- 实际浏览器：社团目录读取本地后端；文化艺术过滤为 3 个，叠加“摄影”搜索为 1 个，无匹配时为 0 个并可清除恢复 6 个。收藏/取消收藏后恢复原状态；详情入口打开摄影社，原有“已加入社团”状态正确。没有提交新的入社申请或修改成员数据。
- 375×812、390×844、768×1024、1440×1000 视口检查：页面无横向溢出；手机固定六个导航入口，桌面显示侧边导航及真实已加入社团。临时视口覆盖已恢复，浏览器错误日志为空。
- 实际截图：`docs/screenshots/community-2026-10-04/mobile.jpg`、`desktop.jpg`。只核对本地浏览器的手机尺寸，不代表已在真实手机或微信小程序中验收。
