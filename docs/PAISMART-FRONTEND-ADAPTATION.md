# PaiSmart 前端适配

2026-10-18，按用户“参考项目里的 PaiSmart 前端，复用它”的要求调整。新的视觉方向优先于此前白绿社群界面的阶段记录。

## 复用范围

来源是本机 `C:/workspace/PaiSmart/frontend`，只读取、提取和适配，没有改动或重启原项目。使用同版本 Naive UI 2.41.0，而不是仅给旧页面换颜色。

- 布局：从上游 AdminLayout/base-layout 提取 header/sider/content 结构、浮动侧栏、折叠和移动抽屉，去掉校园项目不用的布局模式及设置中心。
- 菜单与主题：复用 Naive UI 菜单配置及 #646cff 主色、白色容器、#f7fafc 底色。导航改接现有校园路由，负责人和平台管理员仍分别受原权限约束。
- 登录：适配上游卡片与品牌头部，沿用校园注册和 Session 登录；不复制上游密码本地记忆、JWT、微信绑定或未实现的找回密码。
- 助手：适配会话侧栏、消息区、输入框和快捷键。历史读取、问题发送、工具查询与引用仍连接校园现有接口；没有迁入充值、归档、反馈、WebSocket 或无对应后端的停止按钮。
- 首页重新排布为轮播、招新社团和近期活动；近期活动只展示尚未开始的记录。旧活动仍保留在业务数据库和活动页。社团、详情、个人中心、消息、知识库和负责人页面使用统一容器、表单、按钮和表格主题，但不为换皮重写其业务状态模块。

核心文件位于 `frontend/src/paismart/`；入口是 `frontend/src/App.vue`。来源映射及许可证见根目录 `THIRD-PARTY-NOTICES.md` 和 `licenses/`。

## 保持不变

不修改后端 API、数据库结构、演示业务记录、模型配置和原型归档。没有把 PaiSmart 整仓替换进来，也没有为外观迁入支付、企业组织、多模型配置中心等无关功能。原 CommunityShell 留存，但正常入口已切换为 PaiSmartShell。

## 本轮验证

- `npm run build`：类型检查及生产构建通过。引入组件库后入口 JS 约 537 kB（gzip 约 169 kB），Vite 仍提示单块超过 500 kB；这是待优化的资源体积，不是构建失败。
- `npm run test:prototype`：222 项断言、28 个路由通过。纯原型不调用业务 API。
- `test:business`、`test:ai-workflows`、`test:finance`、`test:check-in`、`test:club-settings` 全部通过，包含原来的失败写入、迟到响应、身份隔离与确认重试检查。
- `test:finance:live -- restored`、`test:check-in:live -- restored`、`test:club-settings:live -- restored` 通过，读取原有持久化验收记录；没有新建或改写这些记录。这些是 HTTP + 真实 Vue 组件 SSR 检查，不等于手机设备验收。
- 实际内置浏览器已检查 1280×900 桌面与 375×812 手机模拟视口：学生登录、退出、侧栏折叠/展开、首页、社团列表、助手、兴趣推荐切换与移动抽屉。375 宽度下上述页面未出现横向溢出。仅是浏览器模拟，未验收真机微信或所有设备。
- 实际浏览器已登录负责人账号，核对招新审核、经费台账及社团设置：显示原有预算/支出与社团资料，退出后设置表单消失。没有点击审核、保存预算或修改资料。
- SSR 使用 `@css-render/vue3-ssr` 正式适配器渲染真实 Naive UI 组件。没有用占位组件绕过样式/DOM 问题。
