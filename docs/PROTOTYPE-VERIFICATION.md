# 交互原型验证记录

日期：2026-10-01。范围：Vue 产品原型与局域网预览启动；未修改 Spring Boot 业务代码，未引入消息队列。

## 已验证

- `npm run build`：TypeScript 类型检查与 Vite 生产构建通过。
- `npm run test:prototype`：用真实 Vue/Vite 模块执行原型状态测试，并对 22 条路由进行服务端渲染。
- 状态验证包含申请提交、空理由/重复申请拦截、关闭招新拦截、审核通过、结果消息、跨社团审核拦截、收藏、报名防重、满额拦截、过去活动与草稿拦截、取消报名释放名额、localStorage 序列化和重置。
- 模拟关闭安全上下文 `crypto.randomUUID`，验证局域网 HTTP 下演示记录 ID 的回退逻辑。演示 ID 不用于认证或安全令牌。
- 本次启动的原型进程在 `0.0.0.0:5178` 监听，独立原型配置没有后端 API 代理。电脑本机请求以下地址均获得 HTTP 200，并包含“社遇”网页标题：`127.0.0.1:5178`、`192.168.31.97:5178`、`192.168.31.141:5178`。IP 是本次运行快照，可能变化。

## 未验证及边界

- 当前 UI 工具没有可用浏览器或原生应用连接，因此未完成真实浏览器点击、截图、像素布局检查、控制台检查、触屏操作及 iOS/Android 真机验收。页面渲染测试不能证明 CSS 无溢出。
- 已编写手机断点布局、底部导航、弹窗与安全区样式，但其实际效果需用户打开手机浏览器确认。
- 未在另一台手机上实测访问；电脑本机访问局域网地址成功不能证明防火墙、Wi-Fi 隔离或手机路由没有问题。未修改防火墙、未开公网隧道。
- 活动表单与弹窗目前经过类型检查和页面渲染，未通过浏览器端到端点击验收。
- 未测试多用户、跨设备同步、真实登录权限、真实报名事务或并发容量控制，因为这些不是当前前端原型的实现范围。
- 旧后端联调页面和 API 保留，但本次未重启 Java 服务，也未重跑后端集成 smoke。原型无需后端或 AI 服务即可加载。

## 用户建议验收

1. 手机打开局域网地址，确认底部五项导航可用。
2. 申请光影摄影社，切换负责人工作台审核，再返回个人中心。
3. 新建未来日期的活动，保存草稿并发布，回学生端报名。
4. 刷新页面，核对记录仍在；尝试满额活动与取消报名。
5. 如遇页面溢出或按钮问题，提供所在页面和截图，以便进一步修正。
