# 首页内容管理

2026-10-06 实现。范围是“平台管理员挑选首页内容”，不是所有社团活动的发布审批。

## 使用方式

打开正常本地开发站点 http://127.0.0.1:5178/login 。demo 配置下使用 `platform_admin` / `CampusDemo123!`，登录后直接进入 `/platform/banners`；桌面侧栏、手机“我的”也有“首页内容管理”入口。正式部署不得使用公开演示账号，正式管理员开户机制仍需另行确定。

新增海报时填写标题、站内关联内容、PNG/JPG 图片、展示时间和顺序。保存后默认为下架，检查无误后点击上架并确认。数字越小越靠前，同序号按记录 ID 排列；开始/结束可留空。下架保留记录，可以再上架。编辑已上架海报会直接更新内容，表单明确提示这一点。

关联内容限定为社团介绍、开放招新的社团、尚未开始的已发布活动。不接受自由外部 URL，也不展示活动草稿。招新入口跳到对应社团详情及招新说明，不是无关的全校列表。

首页每 6 秒轮换，支持指示点、上一张/下一张、暂停/播放、左右方向键和触摸滑动。手动选图会暂停；悬停或焦点进入时暂时停播，系统减少动态效果时不自动播放，离开页面清理计时器和事件。纯原型不读取真实海报或提供模拟平台管理。

## 权限边界

| 角色 | 首页海报管理 | 本人/所属社团原有业务 |
| --- | --- | --- |
| 未登录 | 不可，接口 401 | 可浏览公开社团、已发布活动和有效海报 |
| STUDENT | 不可，接口 403 | 原有学生申请、报名等权限不变 |
| MANAGER | 不可，接口 403 | 原有所属社团管理权限不变 |
| PLATFORM_ADMIN | 可 | 不继承负责人权限，不可冒充学生申请/报名 |

Spring Security 限制 `/api/platform/**`，服务层也核对当前数据库账号角色。登录复用 Session，写入复用 CSRF；注册接口不会采纳请求里的管理员角色。没有前端身份切换提权，也没有增加微服务或复杂权限配置。

## 数据和图片

校园数据库新增 `homepage_banner`，存储标题、关联类型/ID、排序、启用开关、展示时间、图片二进制、服务端内容类型、创建/更新时间和最后操作人。下架不删除。演示配置仅在海报表为空时创建三个原创 SVG 插画与虚构示例，不覆盖后续编辑或下架记录。

用户图片仅 PNG/JPG，2MB 内，宽高各不超过 4096 像素。后端按实际图片内容识别并解码重编码，不信任扩展名或客户端 MIME；用户不能上传 SVG、脚本或任意文件。图片随数据库持久保存，避免额外文件服务。知识资料原有 128KB 限制保留；校园服务 multipart 总限制调整为单文件 2MB / 请求 3MB。

公开列表和图片接口每次请求都检查：已上架、到展示时间、未到结束时间、招新仍开放、活动仍已发布且未开始。失效内容不出现在公开列表，其公开图片返回 404；管理员仍可预览和编辑。开始/截止时间使用现有后端本地时间约定，学校正式部署需统一服务器时区。

这里没有消息推送：已打开的页面不会因另一人取消活动而即时移除已加载海报，重新进入/刷新页面会读取最新状态；展示结束时间也会在轮播计时检查中剔除。多管理员同时编辑仍是最后一次保存生效，没有新加版本锁。

## 接口与源码

| 接口 | 作用 |
| --- | --- |
| GET /api/banners | 公开有效海报及服务端生成的站内跳转 |
| GET /api/banners/{id}/image | 公开有效图片，不缓存 |
| GET /api/platform/banners | 管理员读取全部状态 |
| GET /api/platform/banner-targets | 可关联社团、招新、活动 |
| POST /api/platform/banners | metadata JSON + image multipart，保存下架海报 |
| PUT /api/platform/banners/{id} | 编辑 metadata，image 可省略以保留原图 |
| POST /api/platform/banners/{id}/visibility | 显式 enabled 开关，上架前校验关联内容和有效期 |
| GET /api/platform/banners/{id}/image | 管理员预览下架/失效海报 |

后端 `campus-service/src/main/java/com/campus/business/banner`；前端 `frontend/src/community/CommunityPlatformBanners.vue` 与 `CommunityBannerCarousel.vue`。AI 服务、原 PaiSmart 项目和原型 ZIP 未改动。
