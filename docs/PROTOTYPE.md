# 社遇 · 校园社团交互原型

## 定位

前端以校园社团产品为中心，而不是 AI 演示工作台。学生端和负责人工作台共用一个 Vue 响应式网页，手机无需微信小程序即可访问。所有人物、社团和活动均为虚构公开演示资料。

## 页面与交互

| 区域 | 页面 | 可体验内容 |
| --- | --- | --- |
| 学生 | 首页 `/` | 社团精选、近期活动、招新入口 |
| 学生 | 社团广场 `/clubs`、详情 `/clubs/:id` | 分类、搜索、收藏、招新条件、提交模拟申请 |
| 学生 | 招新 `/recruitment` | 开放申请的社团、申请流程 |
| 学生 | 活动 `/activities`、详情 `/activities/:id` | 分类、搜索、名额筛选、安排、确认报名、取消报名 |
| 学生 | 个人中心 `/me` | 兴趣偏好、入社申请、我的社团、报名和收藏 |
| 学生 | 消息 `/messages` | 模拟申请与报名结果、已读状态 |
| 负责人 | 工作台 `/manage` | 切换管理社团、待办、社团概况 |
| 负责人 | 招新审核 `/manage/recruitment` | 查看理由、填写意见、通过或拒绝 |
| 负责人 | 成员 `/manage/members` | 查看审核通过的模拟成员 |
| 负责人 | 活动 `/manage/activities` | 新建、保存草稿、确认发布、查看新增报名名单 |
| 负责人 | 经费 `/manage/finance` | 活动计划预算汇总；无实际财务操作 |
| 辅助 | `/assistant` | 共同兴趣标签筛选演示、真实资料问答入口 |
| 说明 | `/guide` | 页面流程与实现边界 |
| 联调 | `/system` 及子路由 | 原有真实后端接口联调页，需 Java 服务 |

## 两条推荐体验路径

1. 学生进入光影摄影社 → 申请加入 → 个人中心查看“待审核” → 顶部切换负责人工作台 → 选择光影摄影社 → 招新审核通过当前学生的申请 → 查看成员名单 → 返回个人中心，查看我的社团与消息。
2. 负责人进入活动管理 → 新建活动（填写未来日期）→ 保存草稿 → 编辑并确认发布 → 回到学生端活动列表 → 查看该活动并报名 → 个人中心查看报名 → 负责人查看模拟名单。

也可以尝试搜索无结果、名额已满、重复报名限制、撤回申请、拒绝申请和取消报名。

## 启动与手机访问

外出访问的纯前端临时公网预览与限制见 [公网预览记录](PUBLIC-PREVIEW.md)。它不是永久部署，须保持电脑与预览进程运行。

安装依赖：在 `frontend` 目录运行 `npm install`。

仅启动原型，不需要后端或模型密钥：

```powershell
powershell -ExecutionPolicy Bypass -File C:\workspace\campus-club-platform\scripts\start-prototype.ps1
```

电脑访问 `http://127.0.0.1:5178/`。手机与电脑连接可互通的同一局域网，在手机浏览器打开终端显示的 `Network` 地址，例如 `http://192.168.x.x:5178/`。不能在手机上使用电脑的 `localhost` 地址。

电脑需保持运行。若手机打不开，检查网络是否隔离、IP 是否变化，以及 Windows 防火墙是否允许 Node 在可信专用网络接收入站连接。启动脚本不修改防火墙，也不创建公网隧道；不要直接将开发服务器发布到互联网。

如果 5178 已被旧开发服务占用，先停止自己已启动的该服务，不能同时运行两个同端口前端。`Ctrl+C` 停止前台原型。

## 数据与边界

- 模拟申请、报名、草稿、发布、审核、收藏和兴趣保存在当前浏览器的 `localStorage`，键名为 `campus-prototype-v1`。不写后端数据库，不调用 AI，也不发送真实通知。
- 不同设备、浏览器与访问地址不共享演示记录。手机上要在同一浏览器与同一地址内切换身份，才能体验联动。
- 角色切换不是认证系统。暂未实现真实登录、权限、并发名额控制或多用户协作。
- 卡片上的初始成员数与报名数为宣传/统计样本，不对应个人明细；名单只列出该浏览器新增的模拟记录。
- 标签筛选不是语义 Embedding 推荐；资料问答通过原有真实联调页提供，不用预设回答冒充 AI。
- 地点为自由文本，不增加复杂场地系统。扫码签到、学校级审批、报销、付款和实际余额均未实现。
- 个人中心的“恢复演示数据”只重置原型 localStorage，不改后端资料。

后续按照业务优先级逐条接入正式接口，原型交互不等于毕业设计后端功能已完成。

## 验证

构建：在 `frontend` 执行 `npm run build`，包含 TypeScript 检查。交互与响应式验证记录见 `PROTOTYPE-VERIFICATION.md`；未实测的访问条件不得描述为已验证。
